# 欢迎使用极简笔记

这是一个**纯本地**的 Markdown 笔记应用，笔记以 `.md` 文件保存在 `notes-data` 目录，随时可用其他编辑器打开。

## 快速上手

- 点击右上角 **新建** 创建笔记
- 左侧列表点击切换笔记；点击标题旁的 **铅笔** 图标可重命名
- **删除** 需要二次确认，确认后文件会从 `notes-data` 目录移除
- 停止输入 **1 秒** 后自动保存，右上角显示「保存中… / 已保存」

## 支持的语法

> 引用：先把想法记下来，整理可以慢慢来。

行内代码示例：`npm run dev` 即可启动应用。

```bash
# 代码块示例
npm install
npm run dev
```

| 区域 | 作用 |
| --- | --- |
| 左侧 | 笔记列表（标题 / 更新时间 / 标签） |
| 中间 | Markdown 源码编辑 |
| 右侧 | 实时渲染预览 |

1. 支持有序列表
2. 也支持任务清单：

- [x] 写下第一条笔记
- [ ] 整理本周的想法
